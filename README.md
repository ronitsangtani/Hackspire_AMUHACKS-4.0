# Hackspire_AMUHACKS-4.0
#AMUHACKS4.0 #CSSAMU #AMU

Health Care is a project that we created to enable individuals to access better medical care without necessarily going to a hospital all the time. We understand that not everyone can simply go to a doctor — particularly older individuals, individuals with chronic illnesses, or those who live far from cities. Therefore, we wanted to develop something that allows doctors and patients to remain connected, even at a distance.

With this system, we employ little devices (IoT sensors) that are capable of monitoring critical things such as heart rate, oxygen level, body temperature, and blood pressure. These sensors transmit the health information to an online secure system. Physicians can view this in real-time on their screen, and if there is something that does not seem right, they receive an alert immediately.

We also created a website where:

Physicians are able to log in, review how their patients are doing, and view health history.

Patients are able to log in to view their own health information and have more control over their own health.

We created this project with the aid of tools such as React (for the frontend), Node.js and Express (for the backend), and MongoDB to store all the data. We also used Firebase to enable logging in safely and securely.
